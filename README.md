# Wine Tasting Coach

Product rebuild of the original tasting prototype.

## Product V1

Core modules:

- Tasting
- Library
- Blind Tasting
- Aroma Training
- Progress
- Coach

## Architecture

- Next.js App Router + TypeScript
- Vercel for deployment
- Supabase for Auth and PostgreSQL
- GitHub for source control

## Current branch

`product-v1` contains the new commercial product foundation. The existing HTML prototypes on `main` remain untouched while the rebuild is underway.

## First vertical slice

Login → Tasting → Save → Library

Once this flow works end-to-end, the remaining learning modules will be added on top of the same data model.
